# Customer Segmentation & Retention Analysis

An end-to-end Data Analytics project that analyzes customer purchasing behavior using an e-commerce dataset. The project performs customer segmentation using **RFM Analysis** and **K-Means Clustering**, analyzes customer retention and churn, and presents business insights through SQL, and an interactive Power BI dashboard.

---

## 📌 Project Objectives

- Clean and preprocess customer transaction data.
- Perform Exploratory Data Analysis (EDA).
- Segment customers using RFM Analysis and K-Means Clustering.
- Measure customer retention and churn.
- Analyze business data using SQL.
- Create reports using Excel PivotTables.
- Build an interactive Power BI dashboard.
- Generate actionable business recommendations.

## 📈 Project Results

| Metric | Value |
|---------|------:|
| Total Revenue | ₹39.3 Cr |
| Total Customers | 3,000 |
| Repeat Purchase Rate | 84.4% |
| Customer Retention Rate | 63.6% |
| Customer Churn Rate | 36.4% |
| Revenue from Top 25% Customers | ~61% |

---

## 💡 Key Business Insights

- The **top 25% of customers contribute approximately 61% of total revenue.**
- Customer segmentation identifies high-value, loyal, and at-risk customers.
- The **At-Risk High Spenders** segment should be prioritized through targeted retention campaigns.
- Improving customer retention can significantly increase long-term revenue and customer lifetime value.
